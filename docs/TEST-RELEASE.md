## 光影猫一代飞牛适配测试版

基于 `ophub/fnnas` 的 `fnnas_rockchip_1253` 光影猫镜像，保留飞牛官方 `6.18.18-trim` 内核和 Btrfs 系统。

- 从固定源码编译 Rockchip 网口模块，补齐光影猫 SGMII 能力声明及配套初始化。
- 将 PHY 复位调整到 MAC/MDIO 探测之前，保留原 PHY 地址、GPIO 与延时。
- 同步更新根文件系统与 initramfs 中的网口模块，核对内核标识、导入符号、镜像和启动区。此内核未启用符号 CRC 校验，运行时兼容性须真机确认。
- 内置只读诊断命令 `sudo photonicat-diagnostics`。

**这是尚待真机验收的测试镜像，不代表两个网口和完整电源功能已验证。** 刷入会替换当前系统，先备份配置、容器及数据；不要在依赖它供网时试刷。测试通过前暂不进行飞牛内核 OTA，OTA 可能覆盖适配模块。

下载 `.img.gz` 并核对 `sha256sums`。RKDevTool 线刷前解压成 `.img`，使用光影猫一代 Loader 和完整镜像地址 `0x00000000`；不可当作 OpenWrt sysupgrade 上传。

光影猫接上级路由器获取 IP，浏览器访问 `http://IP:5666`。5G 模组的 USB 地址不是有线网口地址。

请分别测试两个网口的启动、DHCP、千兆协商、传输、重启与断电恢复，并保留诊断输出。模块附件包含对应源码与许可。完整说明见仓库 README。
