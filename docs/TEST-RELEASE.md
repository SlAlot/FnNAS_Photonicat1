## 光影猫一代飞牛适配测试版

基于 `ophub/fnnas` 的 `fnnas_rockchip_1253` 光影猫镜像，保留飞牛官方 `6.18.18-trim` 内核和 Btrfs 系统。

- 从固定源码编译 Rockchip 网口模块，补齐光影猫 SGMII 能力声明及配套初始化。
- 将 PHY 复位调整到 MAC/MDIO 探测之前，保留原 PHY 地址、GPIO 与延时。
- 同步更新根文件系统与 initramfs 中的网口模块，核对内核标识、导入符号、镜像和启动区。此内核未启用符号 CRC 校验，运行时兼容性须真机确认。
- 内置只读诊断命令 `sudo photonicat-diagnostics`。
- LAN 默认 `192.168.17.1`，提供 DHCP、DNS 与 IPv4 NAT；USB 网卡模式的 5G 模组优先上网，有线 WAN 保留自动获取地址。
- 修复 RM500U-CNV 的 NCM 自联网模式被 ModemManager 接管后，NAS 丢失 DNS 的问题。
- LAN 采用手动地址与独立 DHCP / NAT 服务，保存 LAN 设置后继续提供网络共享，地址池随子网调整。
- 设备信息补充内核检测到的 Mali-G52 型号。仅补充硬件信息显示，尚未验证图形计算与视频转码。
- 网页扩展保留原始文件与校验机制，版本不匹配时保留飞牛原生界面。
- LAN 管理口从普通编辑、OVS 和链路聚合中独立出来，降低误操作造成失联的风险。
- 补齐板载 QCA9377 与外接 QCNFA765 的无线驱动及依赖，修正无线频段数据库的签名选择。
- 新增「光影猫热点」管理入口，使用现有管理员账号验证，可自行设置每张网卡的名称、密码、开关、频段和信道。首次开机自动开启：板载 `SlAlot-GLM-2.4G`（2.4 GHz／40 MHz／自动），外接 `SlAlot-GLM`（5 GHz／80 MHz／自动），初始密码均为 `12345678`，请及时修改。已有设置不重置。
- 内置网络面板飞牛原生版 0.1.3（独立 fnos 分支）和光影猫热点 0.3.0，均开机自启；使用现有飞牛管理员账号，统一登录界面并支持记住登录、自动登录。网络面板入口 `http://192.168.17.1:1117/`，热点入口 `http://192.168.17.1:5666/photonicat-hotspot/`。
- 热点改为独立原生插件，随应用提供 hostapd 与可撤销、按内核匹配的 QCNFA765 增强模块。真机已验证板载 2.4 GHz／20 MHz、5 GHz／80 MHz，外接 Wi-Fi 6／80、160 MHz 及 DFS 检测；两路网桥 DHCP、DNS、上网和应用启停恢复已验证。2.4 GHz 的 40 MHz 可能因共存协商降至 20 MHz。实际无线客户端与长期运行仍需测试。
- 补上飞牛内核更新适配：为当前官方 OTA `6.18.18.c1145-trim #1145` 单独编译网口与无线模块，更新时同步处理设备树和 initramfs，保留 LAN 配置。构建中在隔离环境安装官方内核包验证。

**这是测试镜像。一台真机已验证基础有线网络和 5G 联网，新的 OTA 修复仍需一次真机更新和重启验收。** 刷入会替换当前系统，先备份配置、容器及数据。test-10 不含 OTA 修复；尚未适配的未来内核会在安装前停止并提示，需先更新适配版。

下载 `.img.gz` 并核对 `sha256sums`。RKDevTool 线刷前解压成 `.img`，使用光影猫一代 Loader 和完整镜像地址 `0x00000000`；不可当作 OpenWrt sysupgrade 上传。

电脑连接 LAN 口并设为自动获取 IP，浏览器访问 `http://192.168.17.1:5666`；上级路由器接 WAN 口。模组未联网时也可打开本地管理页。5G 模组的 USB 地址不是有线网口地址；原始 QMI / MBIM 模式拨号尚未覆盖。

请分别测试两个网口的启动、DHCP、千兆协商、传输、重启与断电恢复，并保留诊断输出。模块附件包含对应源码与许可。完整说明见仓库 README。
